# Portfolio checklist audit — 4 October 2026

Source: `Portfolio_Website_Checklist.docx`. The site retains its black, lime, Syne, Inter and Space Grotesk design. This is a partial completion report, not a blanket certification. Changes are local and have not been published during this audit.

## Verified and corrected

- **Security:** HTTPS responds successfully; HTTP returns a 301 directly to HTTPS. Live HSTS is present. Static production output includes a hash-based CSP and referrer policy. No deployed database, authentication endpoint, payment handler or form-submission backend exists. Inquiry buttons URL-encode a WhatsApp draft; server-side form validation and CAPTCHA are not applicable to this architecture. `.env` patterns are ignored. Targeted tracked-file scans found no common private-key, GitHub token, AWS access-key or Stripe live-secret signatures. This is not a full-history secret scan. SVG scans found no script, foreignObject or inline load/click/error handlers. Registry audit reported no known vulnerabilities across 428 packages. Four security regression tests pass.
- **SEO:** All 18 canonical pages contain rendered HTML, one H1, unique titles, canonical links and metadata. Titles were shortened. Fixed case-study structured-data image URLs that duplicated the repository base path; removed the unsupported GraphicDesigner schema type and inaccurate hardcoded social-image dimensions. Sitemap and permissive robots.txt exist. Added a real static 404 with home/work/contact links; intentional noindex applies to that error page. Internal links checked successfully. External project and contact links responded; LinkedIn rejects automated HEAD with 405, so its destination is not certified broken or working.
- **Accessibility and mobile:** Tested all 18 pages at 390 and 1440 pixels: zero axe WCAG A/AA violations, no horizontal document overflow, no broken completed images, no runtime errors. Corrected muted text contrast, persistent consultation labels, the budget input name, selection state, counter ARIA semantics, visible focus, skip navigation and small touch targets. Added navigation semantics, expanded state, background inertness, focus containment, Escape and focus restoration. Added slideshow buttons. Functional browser tests pass for menu keyboard navigation, contact validation and encoded isolated WhatsApp handoff, carousel navigation, project filtering and static 404. These are automated desktop-browser emulations, not a real-phone test.
- **Motion and media:** Kept canonical artwork untouched. Added automated lossless 600px carousel derivatives and their manifest entries, and stopped downloading adjacent hidden slides. Added reduced-motion behaviour and playback controls. The decorative video now loads near the viewport with preload disabled; its new 604,380-byte playback copy replaces the 46,547,751-byte download, while the original remains intact. The entrance animation is shorter and no longer hides the static page when JavaScript is unavailable. Fixed a resize-event listener leak. Eight image tests pass, including preservation of originals/full-size outputs and migration of existing carousel manifests.
- **Content:** Removed the explicitly confirmed fictional homepage testimonials and contact quote, including the unsupported conversion/investment claims. Kept case-study quotes, which the owner separately confirmed are approved. Added a concise visible introduction and contact link above the homepage gallery. Corrected the contact response-time metadata and references to an unconnected planned domain in policy text. Existing briefs, processes and scope/results sections remain. Copyright and privacy pages exist.
- **Privacy:** No analytics, advertising or non-essential cookie scripts were found in the reviewed source. A consent banner is consequently not added. Hosting, Google Fonts and WhatsApp data flows are disclosed. These are source/network-architecture checks, not legal advice or a compliance certification.
- **Build:** Production GitHub Pages build and TypeScript check pass. The CSP build secures the static 404 as well. Local preview uses the repository subpath. Chrome functional checks passed across all 18 pages. Test artifacts are retained under `tmp/checklist-audit`.

## Owner-confirmed checks

The owner confirmed GitHub/email two-factor authentication, Google Search Console and Bing sitemap submission, permission to display client work, and font/image licences. These were not independently inspected through account settings. Approved individual case-study quotes are retained. The owner also authorised one test WhatsApp inquiry.
